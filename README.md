## 💡 About

**cualpdf** is a free, native, and open-source desktop PDF manipulator built from the ground up with **C++20** and **Qt 6**.

The goal is simple: provide the essential PDF tools people actually need in a blazingly fast desktop application—**without subscriptions, telemetry, accounts, or unnecessary bloat.**

---

## ✨ Features & Roadmap

### Core Features (In Progress / Planned)
- **Page Operations:** Rearrange, rotate, split, and merge PDFs effortlessly.
- **Crop Tools:** Precise adjustment of `MediaBox`.
- **Optimization:** Fast PDF compression algorithms.
- **Annotations:** Draw, highlight, and add notes directly on pages.
- **Side-by-Side Comparison:** Visually compare two PDF documents simultaneously.
- **Export & Print:** Export pages to images (PNG/JPEG) and advanced print layouts (Single-sided, Duplex, N-up printing).

### 🚀 Future Releases
- **WYSIWYG PDF Editing:** Visual page management and instant previews.
- **Digital Signatures:** Cryptographic signing, PKCS#12 support, and signature validation.

## 🚧 Project Status

**cualpdf** is under active early-beta development and is **not yet recommended for production-critical workflows**.

- **Unsigned Binaries:** Pre-compiled builds for Windows and macOS do not yet carry commercial code-signing certificates. Your operating system (Windows SmartScreen or macOS Gatekeeper) may display a security prompt on first launch.
- Official signed builds and automatic updates will be introduced when the project reaches store-ready maturity.
